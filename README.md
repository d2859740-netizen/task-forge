# Task Forge

A simple and efficient command-line task manager built with Rust.

## Features
- **Add tasks:** Create new tasks with a single command.
- **Remove tasks:** Delete tasks by their number.
- **List tasks:** View all your tasks. Completed tasks are marked with `[x]`, and pending tasks with `[ ]`.
- **Edit tasks:** Change the text of an existing task.
- **Toggle status:** Mark tasks as completed or uncompleted.
- **Save data:** Persist your tasks to a local file (`tasks.txt`).
- **Auto-load:** Automatically loads your saved tasks when the program starts.
